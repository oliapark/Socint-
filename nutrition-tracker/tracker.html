סיכומים שמורים

מדריך: קיצור הדרך באייפון

הקיצור קורא את נתוני היום מאפליקציית Health, מעתיק אותם, ופותח את העמוד הזה. נשאר רק להדביק בתיבת ״פעילות מהאייפון״. ההקמה לוקחת כ־10 דקות, פעם אחת.

  1. באפליקציית קיצורים (Shortcuts): + ← לקרוא לקיצור ״יומן כושר״.
  2. להוסיף פעולה מצא דגימות בריאות (Find Health Samples):
    סוג = צעדים, תאריך התחלה = היום, קיבוץ לפי = יום.
    אחריה קבל פרטים של דגימת בריאות ← ערך, ואז הגדר משתנה בשם steps.
  3. לחזור על אותו דבר (קיבוץ לפי יום) עבור:
    אנרגיה פעילה (Active Energy) ← active
    אנרגיה במנוחה (Resting Energy) ← basal. זה מה שהגוף שורף בלי פעילות, וצריך אותו בשביל חישוב הגירעון.
    דקות אימון (Exercise Minutes) ← exercise
  4. ובלי קיבוץ, עם מיון לפי האחרון והגבלה ל־1:
    דופק במנוחה ← rhr
    משקל ← weight (אם יש משקל חכם שמסונכרן ל־Health)
  5. אופציונלי: מצא אימונים (Find Workouts) עם תאריך התחלה היום ← ספירה ← משתנה workouts.
  6. פעולת טקסט עם השורה הבאה, כשכל שם בסוגריים מוחלף במשתנה המתאים. את התאריך מכניסים כ״תאריך נוכחי״ בפורמט מותאם yyyy-MM-dd: 
    FIT date=[תאריך] steps=[steps] active=[active] basal=[basal] exercise=[exercise] rhr=[rhr] weight=[weight] workouts=[workouts]
  7. העתק ללוח (Copy to Clipboard), ואז פתח כתובות URL עם הקישור לעמוד הזה.
  8. להפעלה יומית: לשונית אוטומציה ← שעה ביום ← 23:30 ← להריץ את ״יומן כושר״. כדאי מאוחר בערב, כי קלוריות המנוחה והפעילות מצטברות לאורך היום. אפשר להריץ שוב מתי שרוצים; ההרצה האחרונה מחליפה את הקודמת.

השמות בעברית יכולים להשתנות מעט בין גרסאות iOS. העמוד מזהה את השורה גם אם הסדר שונה או שחלק מהנתונים חסרים.

דרך נוספת, בלי קיצור: ב־Health מקישים על תמונת הפרופיל ← ״ייצוא כל נתוני הבריאות״, ושולחים את הקובץ export.zip ל־Claude בצ׳אט. כל המדדים והאימונים ייכנסו ליומן.
